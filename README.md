# Module 01: Introduction to AI & Python

This repository contains my work for **Module 01 (Day 1 – Day 4, Beginner)**.
It covers the basics of Artificial Intelligence and Machine Learning, along with
beginner-friendly Python practice programs.

## Learning Objectives
1. Learn the basics of Artificial Intelligence and Machine Learning
2. Understand the difference between AI, ML, and Deep Learning
3. Explore real-world AI applications
4. Install Python and practice programming concepts (variables, loops, functions, lists)
5. Write beginner-friendly Python programs

## Repository Structure

| File | Description |
|------|-------------|
| `variables.py` | Data types, arithmetic, strings, type conversion |
| `loops.py` | `for` / `while` loops, `break`, `continue`, multiplication table |
| `functions.py` | Functions with parameters, default values and return values |
| `lists.py` | Adding, removing, slicing, sorting, list comprehensions |
| `mini_project.py` | Command-line calculator with history (uses everything above) |
| `NOTES.md` | My learning notes for this module |

## How to Run

Make sure Python 3 is installed:

```bash
python --version
```

Run any file:

```bash
python variables.py
python loops.py
python functions.py
python lists.py
python mini_project.py
```

## Mini Project: Simple Calculator
A menu-driven calculator that supports add, subtract, multiply and divide.
It validates input, handles division by zero, and stores a history of calculations in a list.
